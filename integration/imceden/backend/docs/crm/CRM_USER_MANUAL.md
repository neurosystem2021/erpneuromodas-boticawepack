# Manual de usuario

## Acceso

Cuando el administrador habilita el módulo aparece **CRM** en el menú principal.
El acceso conserva la sesión de NeuroRest; no existe una contraseña CRM adicional.

## Flujo básico

1. **Resumen** muestra clientes, tareas pendientes, campañas activas y puntos.
2. **Clientes** permite buscar por nombre, documento o teléfono y revisar RFM.
3. **Segmentos** presenta grupos calculados mediante reglas reproducibles.
4. **Tareas** muestra seguimientos pendientes y sus vencimientos.
5. **Campañas** muestra campañas; no se envían mensajes reales por defecto.
6. **Sincronización** permite al administrador revisar las últimas ejecuciones.

Si aparece “La sesión venció”, vuelva al sistema e inicie sesión. Si el CRM no está
habilitado, NeuroRest continúa funcionando normalmente.
