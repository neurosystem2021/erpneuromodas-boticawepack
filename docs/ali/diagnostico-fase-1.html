Flujo seguro propuesto

Voz/texto → comando local o intención IA tipada → despachador permitido
 → validar sesión/permisos/empresa/almacén → adaptar funciones actuales
 → preparar resumen + versión + UUID → confirmar acción explícita
 → revalidar cambios y verificar pago → ejecutar servicio existente
 → registrar resultado durable → emitir mediante servicio existente
 → consultar evidencia real → imprimir/descargar con recuperación controlada

El modelo no recibe SQL ni acceso directo de escritura. La especificación de herramientas usará strict: true y validación de parámetros propia, con una lista cerrada de acciones. La confirmación no se infiere del texto del modelo. Un resumen caduca si cambian carrito, cliente, almacén, documento o pagos. Un resultado de red incierto se reconcilia antes de permitir un nuevo intento; nunca se vuelve a cobrar automáticamente.

La autorización previa del usuario para que OpenAI pronuncie su nombre se mantiene. No amplía el consentimiento a DNI/RUC, teléfonos, direcciones ni datos de clientes: estos se procesarán localmente.
